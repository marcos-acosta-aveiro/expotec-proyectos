# Expotec 2025 — Sistema de gestión de supermercado

Proyecto académico realizado con Microsoft Excel y Visual Basic for Applications.

## Trabajo realizado

- Diseñé planillas relacionadas para administrar artículos, stock y registro de ventas.
- Desarrollé macros en VBA para automatizar ventas, subtotales y actualización del inventario.
- Implementé formularios de validación para reducir errores de carga y facilitar el arqueo de caja.

## Archivo original y alcance de esta entrega

Se localizó `Gestion Supermercado.xlsm`. La inspección de su estructura muestra hojas de artículos, facturas, proveedores, empleados, usuarios, compras y otras tablas relacionadas. La planilla no se adjunta a esta carga porque necesita una revisión de credenciales, datos personales y macros antes de compartirse.

Este documento describe el proyecto a partir de los datos proporcionados por su autor. No implica que las macros hayan sido ejecutadas o verificadas en esta preparación.
